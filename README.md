# Calculator

A simple and user-friendly calculator web application developed using HTML,CSS and JS(inline). The calculator provides a basic interface for performing common arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear button to reset the display
- Decimal number support
- Simple and clean calculator interface
- Button-based input

## Technologies Used

- HTML5
- CSS3
- JavaScript(inline)

## Project Structure

- calculator.html - Contains the structure and calculator buttons.
- calculator.css - Contains the styling and layout of the calculator.

## Project Preview

The calculator provides a simple interface with a display screen and buttons for numbers and arithmetic operators.

## Purpose

This project was developed to practice and understand the basics of web development, including HTML structure, CSS styling, and JavaScript-based calculator functionality.
